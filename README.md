# BaseBlock — Веб-интеграция для игрового сервера Minecraft 🧱🌐

Репозиторий представляет собой полнофункциональный веб-портал, созданный специально для игрового сервера **BaseBlock**. Сайт обеспечивает глубокую двустороннюю интеграцию с сервером Minecraft, позволяя игрокам взаимодействовать с игровым миром прямо через браузер.

---

## 🌟 Основные возможности системы

### 1. 🔑 Автоматическая интеграция аккаунтов (AuthMe)
Сайт синхронизирован с базой данных игрового сервера Minecraft (через плагин авторизации, например, **AuthMe Reloaded**):
* **Кастомный хешер паролей `BCrypt2aPasswordHasher`**: Реализована безопасная сверка паролей по стандарту шифрования `bcrypt` (с солью `$2a$`), используемому AuthMe.
* **Автоматические учетки**: Игрокам не нужно регистрироваться на сайте отдельно — они заходят под своим игровым никнеймом и паролем прямо с игрового сервера.

### 2. ⚡ Мониторинг игрового сервера в реальном времени
* Интеграция с библиотекой `mctools` (**QUERYClient**) позволяет сайту автоматически опрашивать игровой сервер и выводить на страницы актуальный статус сети и количество игроков онлайн.

### 3. 👤 Личный кабинет игрока (Профиль)
* **3D-визуализация скинов (`skinview3d` + `three.js`)**: Динамическое интерактивное отображение 3D-модели игрока в его личном кабинете.
* **Игровые роли и Донаты**: Отображение статусов (`Role`), уровней влияния (`Donate`) и привилегий, синхронизированных с сервером.
* **Игровые достижения (Achievements)**: Система наград и ачивок за заслуги на сервере.
* **Система судимостей (Convictions)**: RolePlay-составляющая, позволяющая отслеживать судебные решения и приговоры игроков в игровом мире.
* **Социальный рейтинг (Social Rating)**: Интерактивная система кармы игрока на основе его поведения и активности.

### 4. 🗺️ Интерактивная карта и Медиа
* Поддержка интеграции с веб-картой игрового мира (**Dynmap / BlueMap**).
* **Скриншоты и Галерея**: Возможность для игроков делиться своими красивыми постройками и приключениями, загружая скриншоты в общую галерею.

### 5. 📅 Управление ивентами (Event System)
* Создание игровых событий (ивентов) администрацией или игроками.
* Поддержка указания **игровых координат (X, Y, Z)**, времени проведения, интерактивной галереи из 3-х скриншотов и списка зарегистрировавшихся участников.
* Автоматическая валидация времени проведения (нельзя создать ивент в прошлом) и отслеживание статуса (`В ожидании`, `Начат`, `Закончен`).

### 6. 📂 Дополнительные разделы
* **Скачивание модов**: Удобный файловый менеджер для загрузки модов (`mods.zip`) и плагинов, необходимых для комфортной игры на сервере.
* **Новости проекта**: Публикация анонсов и обновлений с привязкой к конкретным серверам проекта.
* **Контакты и Донаты**: Подробное описание способов поддержки сервера.

## 🛠️ Технологический стек

* **Бэкенд**: Django 5.0+, Python, Django Channels (WebSockets)
* **База данных**: MySQL / MariaDB (для полной интеграции с сервером), SQLite (для локальной разработки)
* **Фронтенд**: HTML5, Tailwind CSS, JavaScript (Vanilla ES6)
* **3D Графика**: three.js, skinview3d
* **Внешние библиотеки и API**: Redis (для каналов Channels), `mctools` (Query Minecraft API), `bcrypt`

## 🚀 Быстрый старт и запуск

### 1. Подготовка окружения
Убедитесь, что у вас установлены **Python 3.10+** и **Node.js**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ErrorGhostX/baseblock.git
   cd baseblock
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для macOS/Linux:
   source .venv/bin/activate
   ```
3. Установите зависимости Python:
   ```bash
   pip install -r requirements.txt
   ```
4. Установите npm-пакеты для фронтенда и Tailwind:
   ```bash
   npm install
   ```

### 2. Настройка базы данных
В файле `MinecraftSite/settings.py` укажите параметры подключения к базе данных вашего Minecraft-сервера (раздел `DATABASES`):
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'BaseBlock',
        'USER': 'your_user',
        'PASSWORD': 'your_password',
        'HOST': 'localhost',
        'PORT': 3306,
    }
}
```

### 3. Применение миграций и запуск
1. Сделайте миграции базы данных:
   ```bash
   python manage.py migrate
   ```
2. Запустите сборщик стилей Tailwind:
   ```bash
   python manage.py tailwind start
   ```
3. Запустите сервер разработки Django:
   ```bash
   python manage.py runserver
   ```
4. Откройте в браузере: `http://127.0.0.1:8000`
